# Guitar Hero 5 - PC (recompilación)

Compilación de Guitar Hero 5 para PC a partir de una recompilación estática de la versión de Xbox 360 con ReXGlue.

## Contenido

- `Guitar Hero 5.exe`: el juego recompilado.
- `Guitar Hero 5 Launcher.exe`: lanzador.
- `rexruntime.dll`, `rexgpu-xenos.dll`, `rexgpu-gh5dx12.dll`, `rexgpu-gh5vk.dll`: runtime y plugins de video (DirectX 12 y Vulkan).
- `shaders/`: caché de shaders precompilados.
- `gh5.ico`: ícono.

## Importante

**No incluye ningún dato del juego** (música, modelos, texturas, canciones). Para jugar hace falta tener tu propia copia legítima de Guitar Hero 5 para Xbox 360 y apuntar el lanzador a esos archivos.

Los ajustes (`launcher.ini`, `gh5.toml`) se generan solos la primera vez que abrís el lanzador.
